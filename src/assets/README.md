# Asset Organization

Use this folder structure to keep future portfolio assets organized.

- images/
  - profile/ — profile photos and personal branding images
  - projects/ — project screenshots, thumbnails, and visual assets
- videos/
  - demos/ — project demos, walkthroughs, and recorded clips
- documents/
  - cv/ — CV and resume PDFs
  - certificates/ — certificate PDFs, images, and proof files

Suggested practice:
- Keep file names descriptive and consistent.
- Group project media by project title.
- Use clear names like `vehicle-tracking-thumbnail.jpg`, `vehicle-tracking-demo.mp4`, `cv-english.pdf`.
- Avoid mixing different types of assets in the same folder.
- Add new files here first, then reference them from the data files in `src/data`.
